*A responsive and modern personal portfolio showcasing my skills, education, and full-stack projects.*

## 📌 Project Overview  
The **Personal Portfolio Website** is a web-based portfolio built using **HTML**, **CSS**, and **Bootstrap**, designed to highlight my profile as a **Python Full Stack Developer**.  
It features project showcases with live links, education details, and a professional contact section — all styled for clarity and responsiveness across devices.  

---

## 🧠 Tech Stack  
- **Frontend:** HTML, CSS, Bootstrap  
- **Backend Projects Linked:** Flask, Django  
- **Additional Tools:** React, JavaScript, MySQL  

---

## 🚀 Features  
- Clean, fully responsive design built with Bootstrap  
- Sections for About, Skills, Education, Projects, and Contact  
- Direct links to GitHub repositories and live project previews  
- Includes backend project showcases (Flask & Django)  
- Integrated social and email contact options
